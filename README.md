# BLACKNODE Cyber Lab — College Project

A browser-only, fictional cybersecurity interface for demonstrating UI flows:
- Login screen (any demo username/password works)
- Fictional ₹2,800 package selections (no payment gateway)
- 12-hour visual countdown
- Random terminal command simulation
- Local image preview (the image is not uploaded)
- Test profile form and simulated analysis
- Fictional 80% scenario confidence display with clear disclaimer

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Enter any username and password.
4. Select a package and activate the demo.
5. Try terminal commands: `help`, `scan-demo`, `status`, `clear`.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the Pages URL to appear.

## Important safety notes
This project is a visual simulation. It does not connect to proxy services, dark-web accounts, payment processors, external targets, or phones. It cannot discover a person's IP address or device model from a phone number, Instagram username, or photo. Do not enter real personal information. Use fictional test data only.

All values and status messages are illustrative and must not be presented as proof of real access or hacking.
